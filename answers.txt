1) Hoeffding equation
---------------------
Given:
  N = 43
  E_in = 0.1
  tolerated production error = 0.2

We want to bound:
  P(E_out > 0.2)

Since E_out > 0.2 and E_in = 0.1, this implies:
  E_out - E_in > 0.1

Let eps = 0.1. By one-sided Hoeffding:
  P(E_out - E_in >= eps) <= exp(-2 * N * eps^2)

Therefore:
  P(E_out > 0.2) <= exp(-2 * 43 * 0.1^2)
                  = exp(-0.86)
                  ~= 0.4232

So yes, we can bound the probability:
  P(E_out > 0.2) <= 0.4232

(Using the two-sided form gives
  P(|E_out - E_in| >= 0.1) <= 2 * exp(-0.86) ~= 0.8463.)
